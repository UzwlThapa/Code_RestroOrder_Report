# Restaurant Reports

Recovered from Rocket AI build (browser sourcemap extraction) and reassembled
into a runnable Next.js project.

## Reports included
- IRD Sales Book
- Menu Engineering (Top/Low/Dead items)
- Cost Centre Purchase Report (Kitchen/Bar/Bakery)

Currently uses sample data in `src/app/data/reportData.ts` — replace with real
API calls to your reporting backend when ready.

## Run locally
```
npm install
npm run dev
```
Open http://localhost:3000

## Build for production
```
npm run build
npm start
```
